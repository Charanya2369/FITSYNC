# 👕🏋️ FITSYNC

> AI-Powered Smart Fashion & Fitness Recommendation System

---

## 📌 Overview

FITSYNC is a full-stack web application that combines fashion and fitness into a single intelligent platform. The application provides personalized clothing size recommendations, BMI analysis, workout planning, diet suggestions, and sustainable fashion features to help users maintain a healthy lifestyle while making informed fashion choices.

The system also promotes eco-friendly practices by encouraging clothing recycling and rewarding users for sustainable actions.
