FITSYNC
AI-Powered Smart Fashion & Fitness Recommendation System

📌 Overview
FITSYNC is a full-stack web application that combines fashion and fitness recommendations into one platform.
The application provides personalized clothing size suggestions, BMI analysis, workout plans, diet recommendations, and promotes sustainable fashion through rewards and recycling features.

✨ Features
Secure User Authentication
JWT Authorization
BMI Calculator
Personalized Fitness Reports
Workout Recommendation
Diet Recommendation
Fashion Size Recommendation
Sustainable Fashion Rewards
Clothing Recycling Module
User Profile Management
